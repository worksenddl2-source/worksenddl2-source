## 1. CPTED란 무엇인가

**CPTED**(Crime Prevention Through Environmental Design, 셉테드)는 *범죄예방 환경설계*입니다.
범인을 잡는 것이 아니라 **범죄가 일어나기 어려운 환경을 설계**해 범죄 기회 자체를 줄이는 접근입니다.

| 기본 원리 | 의미 | 예시 |
| :--- | :--- | :--- |
| **자연적 감시** | 사람들의 시선이 자연스럽게 닿는 공간 | 투명한 창, 낮은 담장, 밝은 조명 |
| **접근 통제** | 범죄자가 쉽게 드나들지 못하게 함 | 출입구 정리, 차단봉, 출입 관리 |
| **영역성 강화** | "누군가 관리하는 공간"이라는 인식 | 바닥 포장, 경계 표시, 화단 |
| **활동 활성화** | 사람이 모이고 머무는 공간 | 벤치, 운동기구, 작은 광장 |
| **유지관리** | 방치된 느낌을 없앰 (깨진 유리창 이론) | 낙서 제거, 고장 조명 수리 |

CPTED는 흔히 세대로 나눠 설명합니다.
- **1세대**: 조명·담장·시야 같은 *물리적 환경* 개선
- **2세대**: 주민 참여, 공동체 같은 *사회적 요소*까지 포함
- **이후 흐름**: ICT·데이터를 결합한 *스마트 CPTED*로 확장 중이며, **피지컬 AI가 들어갈 자리가 바로 여기**라고 생각합니다.

## 2. CPTED의 장점

| 장점 | 설명 |
| :--- | :--- |
| **사후가 아닌 사전 예방** | 사건이 난 뒤 대응하는 비용보다, 기회를 줄이는 쪽이 피해자·사회 모두에게 이롭다 |
| **체감 안전도 향상** | 실제 범죄 감소뿐 아니라 주민이 *느끼는* 불안감까지 줄인다 |
| **비교적 낮은 비용** | 조명 교체, 벽화, 시야 확보처럼 작은 개선으로도 효과를 낼 수 있다 |
| **도시 환경 개선 효과** | 밝고 깨끗한 공간은 범죄 예방뿐 아니라 상권·주거 만족도도 높인다 |
| **공동체 회복** | 사람이 모이는 공간을 만들면서 이웃 간 관계와 자율 감시가 살아난다 |
| **처벌 중심이 아닌 설계 중심** | 특정인을 감시·처벌하기보다 *공간*을 바꾸는 접근이라 거부감이 적다 |

## 3. 왜 피지컬 AI가 필요한가

**피지컬 AI**는 화면 속에서만 동작하는 AI가 아니라, 카메라·센서로 현실을 **보고**, 상황을 **판단**하고, 조명·스피커·로봇 같은 장치로 **움직이는** AI입니다.

기존 CPTED는 한 번 설계하면 **고정된 환경**입니다. 하지만 범죄 위험은 시간·날씨·사람 수에 따라 계속 바뀝니다.

| 기존 CPTED의 한계 | 피지컬 AI가 채울 수 있는 부분 |
| :--- | :--- |
| 조명은 항상 같은 밝기 | 사람이 지나가거나 위험 신호가 있을 때 **스스로 밝아지는 조명** |
| CCTV는 많지만 볼 사람이 부족 | AI가 **이상 상황만 골라** 관제 요원에게 알림 |
| 고장·방치를 늦게 발견 | 센서 데이터로 **고장 조명·시설물을 자동 감지** |
| 효과 측정이 어렵다 | 유동 인구·체류 시간 데이터로 **개선 전후 효과를 수치로 확인** |
| 위급 상황에 소리치기 어려움 | **제스처·자세 인식**으로 말없이 구조 요청 |

> 핵심은 **"감시를 늘리는 것"이 아니라 "환경이 똑똑하게 반응하게 만드는 것"** 입니다.
> CPTED가 *공간의 설계*라면, 피지컬 AI는 그 공간에 *반응 능력*을 더하는 기술입니다.

## 4. 접목할 수 있는 기술

`SEE → DETECT → LIGHT UP → PREVENT` 흐름으로 정리했습니다.

| 단계 | 기술 | CPTED 원리 | 활용 아이디어 |
| :--- | :--- | :--- | :--- |
| **SEE** 보기 | 카메라, 열화상, 레이더·PIR 센서 | 자연적 감시 | 어두운 골목·사각지대의 사람·움직임 파악 |
| **DETECT** 판단 | YOLO(객체 탐지), 객체 추적, 이상행동 탐지 | 자연적 감시 | 쓰러짐·배회·싸움 같은 이상 상황 감지 |
| | MediaPipe(포즈·손 제스처 인식) | 접근 통제 | 손짓 하나로 보내는 **무언(無言) 구조 신호** |
| | 음향 AI (비명·유리 깨짐 소리) | 자연적 감시 | 영상이 닿지 않는 곳의 위험 신호 보완 |
| **LIGHT UP** 반응 | 아두이노·마이크로컨트롤러, 스마트 가로등 | 활동 활성화 | 사람이 오면 밝아지고, 위급 시 색이 바뀌는 조명 |
| | 스피커·비상벨, 안내 방송 | 영역성 강화 | "이 공간은 지켜지고 있다"는 신호 |
| **PREVENT** 예방 | 엣지 AI (현장 기기에서 바로 판단) | 전체 | 영상을 밖으로 보내지 않아 **개인정보 보호**에 유리 |
| | 데이터 대시보드, 위험도 지도 | 유지관리 | 시간대별 위험 구역 분석, 순찰·조명 개선 우선순위 결정 |
| | 순찰 로봇·드론 (장기 목표) | 자연적 감시 | 사람이 가기 어려운 시간·장소 보완 |

## 5. 한국에 어떻게 적용할 수 있을까

### 한국은 이미 기반이 갖춰져 있다

- **제도**: 건축법에 범죄예방 기준이 들어가 있고, 국토교통부의 *범죄예방 건축기준*에 따라 일정 건축물은 CPTED를 반영해야 합니다.
- **경찰·지자체**: 경찰은 범죄예방진단(CPO)과 셉테드 사업을, 지자체는 *안심귀갓길*, *여성안심 귀갓길*, 범죄예방 디자인 사업을 운영해 왔습니다. 서울 마포구 염리동 *소금길*은 대표적인 범죄예방 디자인 사례로 알려져 있습니다.
- **인프라**: 공공 CCTV가 많이 설치되어 있고, 지자체마다 **CCTV 통합관제센터**가 운영되고 있습니다.
- **기술 환경**: 높은 통신망 보급률, 스마트시티 사업 등 AI를 붙일 수 있는 토대가 탄탄합니다.

### 그래서 한국에 필요한 것은 "더 많은 CCTV"가 아니라 "더 똑똑한 반응"

| 한국의 상황 | 접목 아이디어 |
| :--- | :--- |
| CCTV는 많지만 관제 인력은 한정됨 | AI가 이상 상황만 골라 보여주는 **지능형 선별 관제** 보조 |
| 원룸·빌라 밀집 지역, 좁은 골목 | 사람을 감지해 켜지는 **반응형 골목 조명** + 비상벨 연동 |
| 1인 가구·심야 귀가 증가 | 안심귀갓길에 **제스처 구조 요청** 기능 추가 |
| 공원·하천 산책로 등 넓은 야외 공간 | 쓰러짐·배회 감지로 **응급 상황 조기 발견** |
| 노후 주거지·재개발 대기 지역 | 고장 조명·방치 구역을 데이터로 찾아 **유지관리 우선순위** 제안 |
| 학교 주변 통학로 | 등하굣길 시간대 위험 요소 분석과 조명·안내 개선 |

## 6. 설계 원칙

기술만큼 중요하게 생각하는 원칙입니다.

| 원칙 | 내용 |
| :--- | :--- |
| **프라이버시 중심 설계** | 얼굴 식별이 아닌 *행동*만 판단하고, 영상은 현장(엣지)에서 처리해 외부로 보내지 않는다 |
| **사람이 최종 판단** | AI는 이상 상황을 *선별*하고, 최종 대응은 관제 요원이 결정한다 |
| **지역 단위 설계** | 한 지점이 아닌 동네 전체의 동선·조명을 함께 설계한다 |
| **주민 참여** | "감시받는 공간"이 아니라 "보호받는 공간"이 되도록 주민과 함께 만든다 |
